# DigitalREN V0.1

デイサービス向けデジタル連絡帳のV0.1検証版です。

## 構成
- フロントエンド: GitHub Pages
- 認証・DB: Supabase
- 認可: Supabase Row Level Security (RLS)
- 利用者データ: GitHubには保存しない

## V0.1
- 職員ログイン
- 当日利用者一覧
- 来所 / 欠席・欠席理由
- 血圧・脈拍・体温
- 任意の連絡メッセージ
- 下書き / 確定
- 家族ログイン
- 紐づいた利用者の確定済み記録のみ閲覧

## 注意
この段階は架空データのみで検証します。実利用者の個人情報は、権限・監査・運用テスト完了後に扱います。
